# Kids Tic-Tac-Toe 🎉

A colorful, touch-friendly Tic-Tac-Toe game designed for children around 4–5 years old.

## Features
- Large 3×3 touch board
- Funny Sun ☀️ vs Moon 🌙 characters
- Big, cheerful win/draw messages
- Play Again button
- Portrait orientation and simple local two-player play
- No ads, accounts, network calls, or external libraries

## Build
Open this folder in Android Studio and build `app` → `assembleDebug`.

The included GitHub Actions workflow also builds the debug APK automatically when pushed to GitHub.
